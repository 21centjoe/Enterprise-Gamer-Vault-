Open the Vault

Enter your passphrase to decrypt your saved game vault (cards, maps, coins, code boxes).

Your passphrase derives a real AES-256-GCM key (via PBKDF2) that never leaves your browser. It encrypts a single file kept in this browser's local storage. There is no password recovery — if you forget your passphrase, that vault file can't be decrypted. This protects your local game data; it is not a bank account, and nothing stored here is real currency.

Credit Codes

Generates a cosmetic code tied to your current coin/key balance and this vault's passphrase-derived key — for use inside your own game (redeeming for in-world items, unlocking a table event, etc).

What's real here, plainly stated: the vault lock on this page uses real AES-256-GCM encryption with a PBKDF2-derived key from your passphrase, protecting the copy of your game data that sits in this browser's local storage. That's it. Coins, keys, and credit codes are in-game currency for your own campaigns — they are not money, cannot be cashed out, aren't tied to any market, and nothing in this file talks to a bank, an exchange, or the internet. If you ever want real payments or redemption, that needs actual financial and legal infrastructure well beyond a single HTML page — happy to talk through what that would involve.
